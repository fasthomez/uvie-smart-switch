# UVie Smart Switch for Windows

A derivative of [UVie Windows](https://github.com/uvie-project/uvie-win), powered by [uvie-rs](https://github.com/uvie-project/uvie-rs). Copyright and MIT/Apache-2.0 license files retained.

Adds **VI/EN language memory per Windows application, browser domain and browser tab**, including tab-specific EN for remote desktop consoles. No OFF mode.

**Status: development prototype; Windows E2E validation outstanding.** See [setup, design and known limitations](docs/SMART_SWITCH.md).
